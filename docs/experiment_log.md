# 실험 로그

모든 실험은 아래 표에 **한 줄씩** 추가합니다. config는 `configs/train/`에 커밋하고,
`results.csv`와 지표 요약은 `docs/experiments/{RUN_NAME}/`에 남깁니다.

## 규칙

1. 명명: `R{번호}_{모델}_{해상도}` — 예 `R9_yolo11n_1280x736`
2. **한 번에 한 변수만** 변경. 해상도와 구조를 같이 바꾸면 원인을 분리할 수 없습니다.
3. `seed=42`, `deterministic=True` 고정
4. 평가는 **고정 test 5,557장**으로만. val 점수는 실험 간 비교에 쓰지 않습니다.
5. `best.pt`는 fitness(`0.1×mAP50 + 0.9×mAP50-95`) 기준이라 **mAP50 최고 에폭이 아닙니다.**
   mAP50이 판정 기준이면 `best_map50.pt`를 쓰고, 어느 쪽을 썼는지 비고에 적습니다.

## 판정 기준 메모

전체 test AP50은 **Drone Detection(DD)이 과대 대표**됩니다. DD는 원본이 640×480이고
bbox 중앙값이 46 px이라, 기업 평가셋(1280×720, 중앙값 9×4 px)과 분포가 정반대입니다.
`ultra_tiny(<8px)` 비중이 DD는 0.5%에 불과합니다.

따라서 소형 객체 개선 여부는 Purdue AP50과 스케일 구간별 Recall로 판정합니다.
